# Week02 - Student Grade Manager

## Overview

This is my Week 02 C++ practice project.

The program allows the user to:

- Enter 5 student scores.
- Calculate the average score.
- Find the highest score.
- Find the lowest score.
- Count the number of passed students (60 or higher).
- Count the number of failed students.

## Concepts Practiced

- Arrays
- Functions
- Passing arrays to functions
- Loops
- if statements
- return values
