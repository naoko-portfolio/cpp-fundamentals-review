# Week 04 - Dynamic Score Manager

## Overview

This is my Week 04 C++ practice project.

The program allows the user to:

- Enter the number of students.
- Dynamically create an array based on the number of students.
- Enter student scores.
- Calculate the average score.
- Find the highest score.
- Add 5 bonus points to all scores.
- Display the updated scores.
- Release dynamically allocated memory.

## Concepts Practiced

- Pointers
- Dynamic memory allocation
- `new` and `delete[]`
- Dynamic arrays
- Passing arrays to functions
- Pointer parameters
- Functions
- Loops
- Return values

## What I Learned

- How to create a dynamic array using `new`.
- How to release dynamic memory using `delete[]`.
- How pointers are used with dynamic arrays.
- How to pass a dynamic array to a function.
- How to pass the array size separately to a function.
- How to access and modify array elements using a pointer.
- The difference between `scores`, `*scores`, and `scores[i]`.
- How to combine pointers, arrays, functions, and dynamic memory in one program.

## Mistakes I Fixed

- Used `*scores` instead of `scores[i]` when entering multiple scores.
- Initially accessed only the first element instead of each element in the array.
- Confused the pointer itself with the value stored at the address.
- Had trouble understanding why the array size needs to be passed separately to a function.
- Fixed errors related to missing braces.
